# shopsphere : E-Commerce Microservices Platform

## Architecture Overview

![Microservice Architecture Diagram](TO-BE-ADDED.png)

## Microservices
- user-service
- product-service
- cart-service
- inventory-service
- notification-service
- payment-service (optional/mocked)
- frontend

## Key Technologies
- Spring Boot 3.x
- React 18+
- Docker
- PostgreSQL / MongoDB
- GitHub Actions, AWS EC2 (for deployment)

---

## Getting Started

### Requirements
- Java 21
- Node.js 18+
- Docker Desktop
- IDE: IntelliJ IDEA (backend), VS Code (frontend)

### Folder Structure
/user-service
/product-service
/cart-service
/inventory-service
/notification-service
/payment-service
/frontend


## Setup Instructions
- Clone the repository
- Set up each microservice as an independent Spring Boot project
- Set up the React frontend project in `/frontend`
- Update this README with service setup, endpoints, and usage
